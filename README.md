# เว็บไซต์พอร์ตโฟลิโอ พรีเวดดิ้ง & งานแต่ง

## ไฟล์ในชุดนี้
| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าเว็บแสดงผลงาน (ลูกค้าเห็น) มีตัวกรองหมวด + ดูภาพเต็มจอ |
| `admin.html` | หน้าจัดการ: อัปโหลดรูป (หลายรูปพร้อมกัน), ลบรูป, คัดลอกลิงก์อัลบั้มส่งลูกค้า |
| `config.js` | **ไฟล์เดียวที่ต้องแก้**: ชื่อสตูดิโอ, ช่องทางติดต่อ, รหัสโฟลเดอร์ Google Drive / คีย์ฐานข้อมูล |
| `supabase-setup.sql` | สคริปต์สร้างตารางและที่เก็บรูปบน Supabase |

## วิธีที่ง่ายที่สุด: ดึงรูปจาก Google Drive (ไม่ต้องใช้ Supabase)
เว็บอ่านรูปจากโฟลเดอร์ใน Google Drive ของคุณโดยตรง เพิ่มรูปลง Drive เว็บก็อัปเดตตาม ไม่ต้องอัปโหลดผ่านหน้าแอดมิน

### 1) จัดโฟลเดอร์ใน Drive ตามนี้
```
ARMORY Portfolio            <- โฟลเดอร์หลัก (ชื่ออะไรก็ได้)
├── พรีเวดดิ้ง
│   ├── U&F                 <- 1 โฟลเดอร์ = 1 อัลบั้ม (ชื่อโฟลเดอร์ = ชื่อบล็อกบนเว็บ)
│   │   ├── 01.jpg          <- เรียงตามชื่อไฟล์ รูปแรก = ภาพปก
│   │   ├── 02.jpg
│   │   └── 03.jpg
│   └── O&B
└── งานแต่งงาน
    └── ต้น & แพรว
```
ตั้งชื่อไฟล์ให้ขึ้นต้นด้วยตัวเลข (01, 02, 03...) เพื่อคุมลำดับ

### 2) แชร์โฟลเดอร์หลัก
คลิกขวาโฟลเดอร์หลัก → แชร์ → การเข้าถึงทั่วไป เลือก **ทุกคนที่มีลิงก์** สิทธิ์ **ผู้ดู**
(รูปในโฟลเดอร์ย่อยจะตามไปเอง) รหัสโฟลเดอร์คือข้อความท้ายลิงก์ หลัง `/folders/`
เช่น `https://drive.google.com/drive/folders/1AbCdEf...` → รหัสคือ `1AbCdEf...`

### 3) ขอ Google API key (ฟรี ใช้เวลาประมาณ 5 นาที)
1. เข้า console.cloud.google.com → สร้างโปรเจกต์ใหม่
2. เมนู **APIs & Services → Library** ค้นหา **Google Drive API** → กด **Enable**
3. เมนู **APIs & Services → Credentials → Create credentials → API key**
4. กด **Restrict key** (สำคัญ เพราะคีย์จะมองเห็นได้ในโค้ดหน้าเว็บ):
   - **Application restrictions:** เลือก *Websites* แล้วเพิ่มเว็บของคุณ เช่น `https://ชื่อผู้ใช้.github.io/*` (ถ้าผูกโดเมนเอง ให้เพิ่มโดเมนนั้นด้วย)
   - **API restrictions:** เลือก *Restrict key* → *Google Drive API*

### 4) ใส่ค่าใน `config.js`
```js
driveFolderId: "รหัสโฟลเดอร์หลัก",
driveApiKey: "API key ที่ได้",
```
บันทึกแล้วอัปโหลดขึ้นเว็บ ไปที่ `admin.html` กดปุ่ม **ตรวจสอบการเชื่อมต่อ** จะบอกจำนวนอัลบั้มและรูปที่พบ

### ข้อควรรู้
- ชื่อโฟลเดอร์หมวดต้องเป็น **พรีเวดดิ้ง** หรือ **งานแต่ง / งานแต่งงาน** (หรือ prewedding / wedding) แก้รายชื่อที่ยอมรับได้ใน `driveCategories`
- อัลบั้มที่วางไว้ในโฟลเดอร์หลักตรงๆ จะนับเป็นหมวดพรีเวดดิ้ง และรูปที่วางหลวมๆ ในโฟลเดอร์หมวด (ไม่อยู่ในอัลบั้ม) จะรวมเป็นบล็อก "รวมภาพ..."
- เว็บจำรายการรูปไว้ประมาณ 5 นาที ถ้าอยากเห็นทันทีหลังแก้ใน Drive ให้เปิดเว็บโดยต่อท้ายลิงก์ด้วย `?refresh=1`
- ใครที่มีลิงก์โฟลเดอร์ก็เปิดดูรูปได้ (ตามที่ตั้งสิทธิ์แชร์) ใช้รูปที่ตั้งใจให้ลูกค้าเห็นเท่านั้น และไม่ควรเก็บงานส่วนตัวในโฟลเดอร์เดียวกัน
- รูปจาก Drive ถูกย่อขนาดให้อัตโนมัติ (กว้างประมาณ 1800px) แต่ไฟล์ต้นฉบับใน Drive ยังคมชัดเหมือนเดิม
- ในโหมดนี้หน้า `admin.html` ใช้เพียงตรวจสอบการเชื่อมต่อและลิงก์ไปที่โฟลเดอร์ ส่วนการตั้ง "จุดโฟกัส" ของภาพ ใช้ได้เฉพาะโหมด Supabase

## เปลี่ยนรูปส่วนบนสุดของหน้าแรก
- ใส่รูปไว้ในโฟลเดอร์เดียวกับเว็บ (ชุดนี้มี `hero.jpg` ให้แล้ว) แล้วตั้ง `heroImage: "hero.jpg"` ใน `config.js` อยากเปลี่ยนรูป ให้ใช้ชื่อไฟล์ `hero.jpg` ทับไฟล์เดิม หรือเปลี่ยนชื่อใน `heroImage`
- `heroFocus` คือจุดที่อยากให้เห็นเสมอเมื่อรูปถูกครอบ เช่น `"50% 49%"` (กลางภาพ ค่อนไปทางกลาง) ถ้าหัวหรือจุดสำคัญขาด ให้ขยับตัวเลขที่สองขึ้นหรือลง (น้อย = ไปทางบนของภาพ)
- ปล่อย `heroImage: ""` ว่างไว้ เว็บจะกลับไปใช้ภาพผลงานสลับกันอัตโนมัติ

## ลองใช้ทันที (โหมดทดลอง)
เปิด `admin.html` ในเบราว์เซอร์ → อัปโหลดรูป → เปิด `index.html` ดูผลงาน
รูปในโหมดนี้เก็บในเบราว์เซอร์เครื่องนั้นเท่านั้น (ยังไม่ขึ้นเว็บจริง)

## ขึ้นเว็บจริงฟรี ทำ 2 ส่วน

### ส่วนที่ 1: ฐานข้อมูล + ที่เก็บรูป (Supabase ฟรี)
1. สมัครที่ supabase.com → New project (เลือก region Singapore)
2. เมนู **SQL Editor** → วางเนื้อหา `supabase-setup.sql` → Run
3. เมนู **Authentication → Users → Add user** สร้างอีเมล/รหัสผ่านของคุณ (ติ๊ก Auto Confirm)
4. เมนู **Authentication → Sign In / Providers** ปิด "Allow new users to sign up" (กันคนอื่นสมัคร)
5. เมนู **Project Settings → API** คัดลอก `Project URL` และ `anon public key` ไปใส่ใน `config.js`
   (ห้ามใช้ `service_role` key)

ข้อควรรู้: แพ็กเกจฟรีมีพื้นที่เก็บไฟล์ราว 1 GB (เว็บนี้ย่อรูปให้อัตโนมัติ ~300-800 KB ต่อรูป จึงเก็บได้หลายพันรูป)
และโปรเจกต์ที่ไม่มีคนใช้งานนานราว 7 วันจะถูกพักชั่วคราว (กด Restore ใน Dashboard ได้)

### ส่วนที่ 2: โฮสต์ตัวเว็บ (เลือกอย่างใดอย่างหนึ่ง)
| บริการ | วิธี | หมายเหตุ |
|---|---|---|
| **Cloudflare Pages** (แนะนำ) | Workers & Pages → Create → Upload assets → ลากโฟลเดอร์ขึ้น | ฟรี ไม่จำกัด bandwidth เหมาะงานเชิงพาณิชย์ |
| **Netlify** | app.netlify.com/drop → ลากโฟลเดอร์ไปวาง | ง่ายสุด ได้ลิงก์ทันที |
| **GitHub Pages** | อัปโหลดไฟล์ขึ้น repo → Settings → Pages | ฟรี |

ไม่แนะนำ Vercel Hobby สำหรับเว็บของธุรกิจ เพราะเงื่อนไขแพ็กเกจฟรีจำกัดการใช้งานเชิงพาณิชย์

หลังขึ้นเว็บแล้ว เข้าหน้าจัดการที่ `https://โดเมนของคุณ/admin.html` แล้วล็อกอินด้วยอีเมลที่สร้างไว้

## จัดการรูปในหน้าแอดมิน
- **เรียงลำดับ:** ลากรูปไปวางในตำแหน่งที่ต้องการ หรือกดปุ่ม ◀ ▶ (ใช้บนมือถือได้) ลำดับนี้ตรงกับที่ลูกค้าเห็นบนเว็บ
- **ภาพปกอัลบั้ม:** คือรูปแรกในอัลบั้ม กด ★ ที่รูปไหนก็ได้เพื่อตั้งเป็นปก
- **แก้ไข (✎):** เปลี่ยนหมวด ชื่ออัลบั้ม หรือคำบรรยาย (เปลี่ยนชื่ออัลบั้ม = ย้ายรูปไปอัลบั้มอื่น)
- **จุดโฟกัส:** กด ✎ แล้วคลิกที่ใบหน้าหรือจุดสำคัญของภาพ หน้าเว็บจะครอบภาพโดยรักษาจุดนั้นไว้ ไม่ให้หัวขาด (ถ้าเคยตั้ง Supabase ไว้แล้ว ให้รัน `supabase-setup.sql` ใหม่อีกครั้ง)
- **เปลี่ยนชื่ออัลบั้มทั้งชุด:** ปุ่ม "เปลี่ยนชื่ออัลบั้ม" ข้างชื่ออัลบั้ม
- **เพิ่มรูปเข้าอัลบั้มเดิม:** ปุ่ม "+ เพิ่มรูปในอัลบั้มนี้" รูปใหม่จะต่อท้ายอัลบั้ม
- ถ้าเคยรัน `supabase-setup.sql` เวอร์ชันเก่าไปแล้ว ให้รันไฟล์ใหม่อีกครั้ง (รันซ้ำได้ ไม่ทำข้อมูลหาย) เพื่อเปิดสิทธิ์แก้ไข/จัดลำดับ

ชื่ออัลบั้มซ้ำกันได้ถ้าอยู่คนละหมวด (เช่น พรีเวดดิ้ง/U&F กับ งานแต่งงาน/U&F) เว็บจะแยกเป็นคนละบล็อก ไม่รวมกัน และลิงก์ส่งลูกค้าจะระบุหมวดไว้ในลิงก์ด้วย

## นำเสนองานลูกค้า
ในหน้าแอดมิน ตั้งชื่ออัลบั้มเป็นชื่อคู่บ่าวสาว แล้วกด **คัดลอกลิงก์ส่งลูกค้า**
ลูกค้าจะเห็นเฉพาะอัลบั้มของตัวเอง เช่น `https://โดเมน/?album=ต้น%20%26%20แพรว`
(ลิงก์ไม่ได้ซ่อนรหัสผ่าน ใครมีลิงก์ก็เปิดได้ และรูปยังขึ้นในหน้าผลงานรวมด้วย)

## โดเมนของตัวเอง
ทั้ง 3 บริการผูกโดเมนได้ (ซื้อโดเมน .com หรือ .in.th ประมาณปีละไม่กี่ร้อยบาท) หรือใช้ลิงก์ฟรีที่ให้มาก็ได้
